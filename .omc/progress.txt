## Strategy adjustments vs spec

1. The Sandbox interface is bigger than the spec listed. Implementing the actual interface is required so all 77 importers keep working.
2. Pi uses models.json not models.yml — spec wording is misleading.
3. Pi tool format is TypeBox + AgentToolResult — different from the AI SDK Zod tool format. Adapter needed.
4. @vercel/workflow swap: 14 files use it. Build a local-workflow shim that satisfies the surface used (getWritable, getRun, sleep, getWorkflowMetadata) rather than rewriting all 14.
5. ToolLoopAgent (`ai` package) and the pi session are very different runtimes. Wire pi as an opt-in backend behind AGENT_BACKEND env so existing path still works during the transition.
6. Docker daemon is currently NOT running on the host machine — code can be written and type-checked, but the LocalDockerSandbox integration test must be run by the user once they start Docker Desktop.
7. Vercel auth, GitHub App, Cloudflare tunnel, DNS, API keys, and pi OAuth all require user action — captured in DEPLOYMENT.md.
