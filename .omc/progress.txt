## Strategy adjustments vs spec

1. The Sandbox interface is bigger than the spec listed. Implemented the actual
   interface so all 77 importers keep working.
2. Pi uses models.json not models.yml.
3. Pi tool format is TypeBox + AgentToolResult — adapter layer in
   packages/pi-agent/src/tools.ts bridges from the existing AI SDK Zod tool
   format.
4. @vercel/workflow swap: built local-workflow shim (workspace package literally
   named "workflow") that satisfies the surface used. v1 is in-memory; rack
   reboot kills in-flight runs (acceptable per spec §8).
5. ToolLoopAgent and pi session are very different runtimes. Wired pi as opt-in
   backend behind AGENT_BACKEND env so existing path still runs untouched.
6. Docker daemon was NOT running on host machine — code authored and
   typechecked, but the LocalDockerSandbox integration test runs on the rack
   once Docker Desktop is up.
